# Tutoring JavaFX Starter

A minimal Maven-based JavaFX application for introducing desktop UI development.

## Learning goals

- JavaFX application lifecycle
- FXML views and controllers
- Maven-based local execution

## Run

Run `./mvnw test`, then `./mvnw javafx:run`.
